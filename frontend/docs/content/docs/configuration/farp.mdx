# FARP & discovery

FARP (the Forge API Gateway Registration Protocol) provides service discovery and automatic
routing. The `farp` section is optional and disabled by default. For conceptual depth, see the
[FARP](/docs/farp) section.

```yaml
farp:
  enabled: true
  watch_interval: 5s
  schema_cache_ttl: 5m
  discovery:
    backends:
      - type: kubernetes
        enabled: true
        config:
          namespace: default
          label_selector: "app.kubernetes.io/part-of=myapp"
          watch_interval: 10s
```

## `farp`

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | boolean | `false` | Enable FARP service discovery and auto-routing. |
| `watch_interval` | duration | `5s` | Interval for discovering service changes. |
| `schema_cache_ttl` | duration | `5m` | Schema cache time-to-live. |
| `discovery` | object | none | Discovery backend configuration. See [below](#discovery). |
| `registration_token` | string | none | Token callers must present to register, update or remove services. See [Registration token](#registration-token). |

## Registration token

With `registration_token` set, every FARP request whose method is not `GET` or `HEAD` needs the
token, on all of the `/_farp/v1`, `/__farp`, `/__/farp` and `/farp` prefixes. Send it as
`Authorization: Bearer <token>` or as `X-Octopus-Farp-Token: <token>`. A request without it gets
a `401` with `WWW-Authenticate: Bearer realm="octopus-farp"`. Reads stay open.

```yaml
farp:
  enabled: true
  registration_token: "${OCTOPUS_FARP_TOKEN}"
```

Read the token from the environment rather than writing it into the file. A `${VAR}` that is not
set fails the config load, so a missing secret stops the gateway instead of leaving registration
open. The token is held as a SHA-256 digest, never serialized into config output, and never
logged. An empty string counts as no token.

If FARP is enabled with no token, the gateway starts and logs a warning. See the
[FARP registration API](/docs/api/farp#authentication) for the exact request and response shapes,
including what a service should do when a heartbeat comes back `404` after a gateway restart.

## Discovery

`farp.discovery` holds a list of discovery backends.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `backends` | array | `[]` | Discovery backends. Each is tagged by `type`. |

Each backend entry has a `type` (`mdns`, `dns`, `consul`, or `kubernetes`), an `enabled` flag
(default `true`), and a backend-specific `config` object.

<Tabs items={['mDNS', 'DNS', 'Consul', 'Kubernetes']}>

<div title="mDNS">

```yaml
- type: mdns
  enabled: true
  config:
    service_type: _http._tcp
    domain: local.
    watch_interval: 10s
    query_timeout: 2s
    enable_ipv6: true
```

`type: mdns`: mDNS/Bonjour discovery.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `service_type` | string | none | Service type to discover. **Required.** |
| `domain` | string | none | mDNS domain. **Required.** |
| `watch_interval` | duration | none | Watch interval. **Required.** |
| `query_timeout` | duration | none | Query timeout. **Required.** |
| `enable_ipv6` | boolean | `true` | Enable IPv6 discovery. |

</div>

<div title="DNS">

```yaml
- type: dns
  enabled: true
  config:
    servers: ["10.0.0.53:53"]
    domain: services.internal
    watch_interval: 30s
```

`type: dns`: DNS-based discovery.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `servers` | array of string | none | DNS server addresses. **Required.** |
| `domain` | string | none | Domain to query. **Required.** |
| `watch_interval` | duration | none | Watch interval. **Required.** |

</div>

<div title="Consul">

```yaml
- type: consul
  enabled: true
  config:
    address: http://consul:8500
    datacenter: dc1
    token: "${CONSUL_TOKEN}"
    watch_interval: 10s
```

`type: consul`: Consul discovery.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `address` | string | none | Consul address. **Required.** |
| `datacenter` | string | none | Datacenter. **Required.** |
| `token` | string | none | ACL token. |
| `watch_interval` | duration | none | Watch interval. **Required.** |

</div>

<div title="Kubernetes">

```yaml
- type: kubernetes
  enabled: true
  config:
    namespace: default
    label_selector: "app.kubernetes.io/part-of=myapp"
    watch_interval: 10s
    use_endpoint_slices: true
    include_not_ready: false
```

`type: kubernetes`: Kubernetes discovery.

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `namespace` | string | none | Namespace to watch. **Required.** |
| `label_selector` | string | none | Label selector for filtering. |
| `watch_interval` | duration | none | Watch interval. **Required.** |
| `use_endpoint_slices` | boolean | `true` | Prefer the `discovery.k8s.io/v1` EndpointSlice API (falls back to Endpoints if unavailable). |
| `include_not_ready` | boolean | `false` | Include endpoints whose `ready` condition is false/unknown. |

</div>

</Tabs>

<Callout type="info">
  The `farp.discovery.kubernetes` backend is independent of the in-process Gateway API controller
  configured under [`kubernetes`](/docs/configuration/kubernetes). See [Kubernetes](/docs/kubernetes)
  for how the two relate.
</Callout>
